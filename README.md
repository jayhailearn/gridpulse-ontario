
# GridPulse

## Weather-Aware Electricity Demand Forecasting and
Peak-Stress Prediction for Ontario's Power Grid

### Overview

GridPulse is an applied machine-learning project
designed to forecast hourly electricity demand in
Ontario and identify periods of unusually high demand.

The project combines historical electricity demand,
weather information, and calendar features to support
data-driven electricity system planning.

### Project Objectives

1. Forecast hourly electricity demand over a
   24-hour prediction horizon.
2. Identify periods of exceptionally high demand.
3. Compare forecasting models against simple baselines.
4. Explain important demand drivers.
5. Develop an interactive visualization dashboard.

### Data Sources

- Independent Electricity System Operator (IESO)
- Open-Meteo Historical Weather API

### Planned Technologies

Python, Pandas, NumPy, DuckDB, scikit-learn,
XGBoost, SHAP, Streamlit, Git and GitHub.
